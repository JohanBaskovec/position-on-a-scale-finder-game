# Le Curseur

Jeu de soirée pour 2 équipes sur un seul téléphone : faites deviner une position entre deux concepts
opposés avec un seul mot.

- Règles : [`docs/REGLES.md`](docs/REGLES.md)
- Spécification : [`docs/SPEC.md`](docs/SPEC.md)
- Paires de concepts : [`docs/CONCEPTS.md`](docs/CONCEPTS.md)
- Décisions de conception : [`docs/DECISIONS.md`](docs/DECISIONS.md)

## Jouer

Ouvrir `index.html` dans un navigateur (de préférence sur téléphone, en portrait). Aucune installation,
aucune connexion nécessaire. Pour héberger le jeu : copier `index.html`, `style.css` et `js/` sur n'importe
quel hébergement statique (GitHub Pages…).
